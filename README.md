## 📋 Module Breakdown

### 🔵 Data Types & Variables
```python
# Primitive types
name    = "Anurag"        # str
age     = 21              # int
cgpa    = 8.5             # float
active  = True            # bool

# Type conversion
num_str = str(42)         # "42"
num_int = int("99")       # 99
```

### 🟣 Control Structures
```python
# Conditional
if marks >= 90:
    print("Grade: A")
elif marks >= 75:
    print("Grade: B")
else:
    print("Grade: C")

# Loops
for i in range(1, 6):
    print(f"Iteration {i}")
```

### 🟠 Functions
```python
# Basic function
def greet(name):
    return f"Hello, {name}!"

# Lambda
square = lambda x: x ** 2

# Recursion
def factorial(n):
    return 1 if n == 0 else n * factorial(n - 1)
```

### 🟡 Object-Oriented Programming
```python
class Student:
    def __init__(self, name, roll):
        self.name = name
        self.roll = roll

    def display(self):
        print(f"Name: {self.name} | Roll: {self.roll}")

class GradStudent(Student):         # Inheritance
    def __init__(self, name, roll, thesis):
        super().__init__(name, roll)
        self.thesis = thesis
```

### 🟢 Data Structures
```python
# List
marks = [85, 90, 78, 95]

# Dictionary
student = {"name": "Anurag", "age": 21, "cgpa": 8.5}

# Set
unique_ids = {101, 102, 103}

# Tuple (immutable)
coordinates = (28.6, 77.2)
```
